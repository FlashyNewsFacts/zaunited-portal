# Official artwork

The portal uses ZAUNITED's **approved, already-public branding**. It may be
cropped and resized, but never redrawn, recoloured, re-lettered or replaced
with generated artwork. Never add private or unreleased StoryForge assets.

## Source files (masters, not served to visitors)

| File | Size | What it is |
| --- | --- | --- |
| `src/assets/brand/zaunited-banner.png` | 2172 × 724 | Official YouTube banner |
| `src/assets/brand/zaunited-profile.png` | 1254 × 1254 | Official profile picture |
| `src/assets/brand/hollowing-art.png` | 1670 × 941 | "Help King Mesmer and the Zaunites fend off the Hollowing!" illustration |

## Where they are used

| Use | Source | Adaptation (crop/resize only) |
| --- | --- | --- |
| Hero on phones and tablets in portrait (under 900px wide) | Banner | Centre 3:2 crop: Mesmer, title, laurels and motto. AVIF/WebP at 640, 960 and 1086px wide (about 40–77 KB AVIF) |
| Hero on wider screens | Banner | Whole banner, uncropped. AVIF/WebP at 1200, 1600 and 2172px wide (about 72–155 KB AVIF) |
| Fallback for older browsers | Banner | 3:2 crop as JPEG, 960px wide |
| `public/og-image.jpg` (link previews) | Banner | Centre crop, 1200 × 630 |
| `public/apple-touch-icon.png` | Profile picture | Whole badge, 180 × 180 |
| `public/favicon-32.png`, `public/crest-96.webp` | Profile picture | Mesmer's face and crown, cropped (the whole badge is unreadable at tab-icon size) |
| Hollowing section, above the countdown | Hollowing illustration | Whole image, uncropped. AVIF/WebP at 480–1670px wide, JPEG fallback; loads as the visitor scrolls near it. The countdown stays live text. |

The hero images are generated at build time by Astro (`src/components/Hero.astro`).
The `public/` files are generated by:

```sh
node scripts/prepare-brand-icons.mjs
```

The banner already shows "ZAUNITED", "The Kingdom of Zaun" and the motto, so
the page keeps those words as hidden text (for screen readers and search
engines) instead of printing them over the art.

## Replacing or adding artwork

1. Replace the master file in `src/assets/brand/` with the same name, or add a new one.
2. Run `node scripts/prepare-brand-icons.mjs` if the profile picture or banner changed.
3. Check the crops on an iPhone, an iPad and a desktop before merging.

A higher-resolution banner (2880px wide or more) would make the hero sharper
on large desktop screens. It can be swapped in at any time without code changes.

New artwork placements need the owner's approval of the exact placement first.
